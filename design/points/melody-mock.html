  1. Where it sits: a fourth choice beside Stretch · Rhythm · Grains on the point's card; switching costs nothing, it reads the same recording.
  2. The slices are found when the recording is attached (on the page, kept in the point, so the apps read the same ones). slices sets how many (2–8), sensitivity how readily an onset counts. Each slice is heard at its own pitch; an unpitched slice (a knock, a breath) moves by the chord's intervals instead.
  3. In tune: a note is a chord degree (root · 3 · 5 · 7 · 9) of the chord under the walker, in the register's range, so the same line re-voices itself on each chord of the route. A slice plays like a sampler: higher is also shorter.
  4. vary moves a note to a neighbouring chord tone or another slice now and then, seeded, as the other devices vary. original · melody is the same fuse knob as Stretch and Grains.
  5. A new Melody point starts with a generated line, so it sounds the moment it is chosen. Every setting is in the shared core, so the website and both apps play it alike.
