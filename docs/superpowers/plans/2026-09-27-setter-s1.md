# Setter S1 — the frame, drawing, the setter cards, Archive, Publish

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Signed in, the setter works entirely inside the new frame (web/listener.js): draw points and routes, edit a feature's card, browse the archive, publish — and the old header, sidebar and bottom sheet are no longer shown to anyone.

**Architecture:** Re-home, don't rebuild. The old setter blocks (`#card`, `#pane-list`, `#publishbar`, `.modes`, `#setter`, `#storage .actions`, `#audit`, the world switch and place list) keep every handler they have; web/listener.js moves them into its panel, sheets and top area when signed in, and web/listener.css restyles them in the new language. The bridge grows only the few calls that have no element to move (draft vertex count, Undo vertex, Done).

**Spec:** `docs/superpowers/specs/2026-09-27-setter-redesign-design.md` (design 1, 2, 3, 4, 6; stage S1).

## Global Constraints

- Nothing the setter can do today may stop working: every moved block keeps its element ids and handlers.
- Tokens only (index.html `:root`); faces display / body / mono as the listener; targets ≥ 44 px.
- No page scroll at 390×844 and 1440×900 in any S1 state (C-8); a long archive scrolls inside its sheet.
- Signed out, the listener is exactly as live (web_listener.mjs listener half stays green).

## Review Focus

1. Signing out while a setter card is open: the card must go back where it came from (or close) and the listener card show — no orphaned setter controls for a listener.
2. Point mode tap on a spot where a feature already is: the old handler creates a point; that stays (it is today's behaviour).
3. The phone: the old code calls openSheet() on select — with #panel hidden it must not steal the screen or scroll.
4. A route drawn with fewer than 2 vertices and Done: nothing created, the mode stays, no error.
5. Resize across 860 px with a setter card open.
